Examples and tips

Continue later

  1. Choose File > Save Game and select a .mahjongg file.
  2. Close the game. If asked whether to save the unfinished game, choose the appropriate response.
  3. Later, start the game and use File > Load Game to open the file. The saved clock and undo history are restored.

Recover from a difficult position

Try Backup to restore a pair, or use Resuffle to rearrange remaining tiles. A successful reshuffle clears undo history. To replay the exact starting layout, choose Restart Game.

Improve your play

  • Look for pairs that uncover higher layers or release a blocked side.
  • Keep an eye on tile counts and the timer in the status bar.
  • Use pause when stepping away; the clock will not advance.
