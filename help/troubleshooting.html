Troubleshooting and FAQ

Common problems

Tile images could not be loaded
Check that the res\tiles folder and all PNG files are alongside the executable. Reinstall if files are missing. Do not move only the executable out of its installation folder.
Help cannot be opened
Check that Help-en.chm and Ohje-fi.chm are beside the executable. Windows may block CHM content downloaded from the Internet: use the file's Properties dialog to unblock a trusted file, or reinstall it locally.
Invalid or unreadable game file
Open a valid MikasMahjongg .mahjongg save; incomplete or unsupported files are rejected. Keep a separate backup before replacing an important save.
Cannot save
Check the destination path, available space, and write permissions. Try a different folder. The game reports Windows error codes when a temporary file or replacement cannot be written.
Invalid language configuration
Check language.ini: the [Language] section must specify Code=en or Code=fi. Restart after correcting the file.
Hall of Fame error
Check that the current user can access its Windows registry profile. Corrupt results are reported rather than silently discarded; clearing the list removes all results after confirmation.

Frequently asked questions

Does every deal have a solution?
Each new deal has a verified solution. A player's later choices can still lead to a dead end.
Do hints prevent a Hall of Fame entry?
No. Hints, undos, and reshuffles are recorded, but assisted wins can qualify.
Can I undo a reshuffle?
No. A successful reshuffle clears the undo history; restart restores the original deal.
Why are some commands gray?
They are placeholders for features not implemented in the current version.
