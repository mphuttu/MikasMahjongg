Technical information

Platform
The installer targets 64-bit Windows 10 or later. The application uses MFC, Direct2D, Windows Imaging Component, and the Microsoft Visual C++ runtime. The installer deploys its MFC and C++ runtime DLLs locally.
Saved games
.mahjongg files contain a versioned text representation of the deal, position, undo history, and statistics. The game validates their contents before loading. Do not edit them manually.
Results and settings
The Hall of Fame is stored in the current Windows user's registry. Toolbar settings and recent-file lists are also user-specific; settings are separated by interface language.
Images and help
PNG tiles are loaded from res\tiles beside the executable. The two CHM files and language.ini are also expected alongside the executable.
Architecture
The game model implements tile matching and deals; the MFC document owns the game and clock, while the Direct2D view draws the board and handles input. The application is a desktop single-player game.
