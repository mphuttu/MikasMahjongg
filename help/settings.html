Configuration and customization

Language

The installer language selects the game language. To change it, reinstall and select another language, or edit language.ini in the application folder while the game is closed. Use [Language] followed by Code=en or Code=fi, then restart the game. If the file is absent, the game defaults to English; an invalid code is reported at startup.

Windows-owned dialogs and system buttons can use the Windows display language. The MFC toolbar customization dialog remains English in the Finnish version.

Toolbars and status bar

Use the View menu to show or hide the status bar and toolbars. The toolbar includes Backup and Restart. MFC toolbar customization and docking settings are stored separately for each interface language.

Limitation: The grayed-out Preferences commands are placeholders; sound, automatic pause, and full-screen options cannot currently be changed through that menu.
