Release notes

Version 1.0

Provides the turtle layout, verified solvable deals, save/load, undo, restart, hints, reshuffle, pause, Hall of Fame, victory animation, bilingual interface and help, and a per-user x64 installer. This maintenance update refreshes the main icon and expands the English help.

Known limitations

  • Several menu options, including sound and printing, remain unavailable.
  • Windows-owned dialogs follow system localization; the Finnish version's MFC toolbar customization dialog is English.
  • Reshuffling clears the undo history, and a hint does not guarantee a win.
