Getting started

Install

Run the 64-bit MikasMahjongg setup on Windows 10 or later. Select English or Finnish in the installer, choose a destination, and follow the prompts. The installer places the required Microsoft C++ and MFC runtime files in the application folder; administrator rights are not required for the default per-user installation.

First launch and quick start

  1. Start MikasMahjongg from the Start menu or run its executable.
  2. Find two matching tiles that are not covered and have a free left or right side.
  3. Click each tile. A selected tile has a yellow outline; click it again to deselect.
  4. Remove all 144 tiles. Use Help > Show Moves if you need a hint.

Tip: The starting position is solvable, but a valid move or hint does not guarantee that the rest of the game remains solvable.
