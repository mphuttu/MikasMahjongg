Feature reference

File > New Game (Ctrl+N)
Creates a new solvable deal. An unfinished game can be saved before it is replaced.
File > Load Game (Ctrl+O)
Opens a saved .mahjongg file. Choose a valid file in the Open dialog. The current unfinished game can be saved first.
File > Save Game (Ctrl+S) / Save As
Saves the current position, elapsed time, statistics, original deal, and undo history. Save As writes a new file. For example, save before quitting and load that file to continue.
File > Restart Game / Restart toolbar button
Restores the original deal and resets the timer and statistics. The game prompts before replacing an unfinished position.
Edit > Undo (Ctrl+Z) / Backup
Restores the last removed pair. Repeat to undo earlier moves. A successful reshuffle clears the undo history.
Help > Show Moves
Highlights an available matching pair. A hint is a legal move, not a guarantee of victory, and is counted in the statistics.
Help > Tiles Left
Displays the number of tiles remaining.
Help > Resuffle
Rearranges remaining tiles into a solvable position when possible. The existing position is preserved if no solution is found; undo moves and try again. The menu uses the spelling shown here.
Special > Pause (Alt+P)
Stops the clock and displays an animation. Select OK to resume. The clock also stops while a saved game is closed.
Special > View Hall of Fame
Shows the ten fastest recorded wins and their hint, undo, and shuffle counts. Wins with assistance can qualify. A qualifying player is prompted for a name after the victory animation.
Special > Clear Hall of Fame
After confirmation, removes the entire list for the current Windows user.
Help > Help Contents
Opens this help file. The installed language determines which help file opens.

When no moves remain, the game offers to restart the same deal. After a win, a six-second celebration runs without adding to the game time; the game then offers a new game or exit.

Note: Grayed-out menu items, including preferences and printing, are not implemented in this version.
