MikasMahjongg - help

This game was inspired by Ron Balewski's Mahjongg.

Objective and rules

Remove all 144 tiles from the turtle layout by clicking two matching free tiles. The selected tile is highlighted in yellow. Click it again to deselect.

A tile is free when no tile covers it and at least one of its left or right sides is free. Tile faces in the same layer meet, while exposed sides and the offset of higher layers help distinguish overlapping tiles. Flowers match any other flower, and seasons match any other season. All other tiles must be identical.

Commands

File > New Game (Ctrl+N)
Starts a new game.
File > Load Game (Ctrl+O), Save Game (Ctrl+S), and Save As
Loads or saves a .mahjongg file, including elapsed time, the original deal, and undo history.
File > Restart Game or the Restart toolbar button
Restores the original deal and resets the clock.
Edit > Undo (Ctrl+Z) or the Backup toolbar button
Restores the last removed pair. Multiple pairs can be undone.
Help > Show Moves
Highlights one available pair. A hint does not necessarily lead to a win.
Help > Tiles Left
Shows the number of remaining tiles.
Help > Resuffle
Rearranges the remaining tiles. A successful shuffle is solvable and clears the undo history. If no solution is found, the position is unchanged; undo moves and try again.
Special > Pause (Alt+P)
Stops the clock and displays an animation. Press OK to resume.
Special > View Hall of Fame
Shows the ten fastest wins and the assists used. Wins with assists also qualify.
Special > Clear Hall of Fame
Clears the entire list after confirmation.

Tips

Every new deal has at least one solution, but not every choice leads to a win. When no moves remain, restart the same deal or continue, for example by undoing. After a win, a celebration plays without adding to the game time; you can then start a new game or exit.

The status bar displays elapsed time. The clock stops while paused or while the game is closed. When closing or replacing an unfinished game, you can save it first. Grayed-out menu commands are not yet available.
