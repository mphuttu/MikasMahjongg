Welcome to MikasMahjongg

MikasMahjongg is a Windows Mahjong solitaire game inspired by Ron Balewski's Mahjongg. Clear a classic 144-tile turtle layout by matching pairs of free tiles.

Features

  • Solvable initial deals and layered tile graphics.
  • Save and load games, restart a deal, undo moves, request hints, and reshuffle.
  • Timed games, a Hall of Fame, pause animation, and a victory celebration.
  • English and Finnish interfaces and help.

The game is intended for players who enjoy single-player tile-matching puzzles. It is not the multiplayer Mahjong game.
